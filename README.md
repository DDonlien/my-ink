# 墨线 · Ink Loom

以 Markdown 为内容源的 Ink 编辑与预演工具。用文字编写世界规则、对话和行为意图，在网页中观察它们如何推进。

## 启动

需要支持 Vite 8 的 Node.js 版本；本次在 Node.js 26 上验证。

~~~sh
npm ci
npm run dev
~~~

打开 http://127.0.0.1:4317/ 。所有编辑和预演都在本地完成，无需账号或后端。

~~~sh
npm test
npm run build
npm run preview
~~~

构建产物在 dist/，预览地址为 http://127.0.0.1:4318/ 。

已部署到 NAS 的外网地址：[墨线 Web](https://git.freshli4.com:10443/ink/)。公网构建使用 `npm run build:public`，资源前缀为 `/ink/`。NAS 独立托管生产构建，不依赖本机开发进程；文档和预演进度仍保存在访问设备的浏览器中，不会自动同步设备。

配置与更新说明见 [deployment/README.md](deployment/README.md)。

## 设计系统

全站按 [Material Design 3 Expressive](https://design.google/library/expressive-material-design-google-research) 调整。紫色墨水作为主色，暖杏色用于文档和行为，青绿用于世界事实；顶栏采用胶囊选中形状，按钮在点击时变化圆角。演绎正文在桌面使用 18px、窄屏使用 17px，选项、表单、菜单、节点编辑及原文和教程弹窗共用同一套色彩、形状、焦点与动效规则。

设计变量集中在 `src/design/tokens.css`。界面使用本地托管的 Roboto Flex 拉丁字体和 [Material Symbols Rounded](https://developers.google.com/fonts/docs/material_symbols)，中文使用设备的系统字体，演绎正文使用中文衬线字体。字体、来源和许可证保存在 `public/fonts/`，打开站点时不依赖外部字体服务。系统开启减少动态效果后，按钮、弹窗和正文自动滚动均使用减少动效的方式。

剧情图的字号与确定性排布测量同步调整；缩放按钮位于右下方，段落栏和拖拽提示占用独立位置，避免覆盖对白。页签、编辑和剧情执行沿用现有功能。

全站滚动条仅在对应区域滚动时显示，停止 650 毫秒后淡出。页面、节点面板、输入框、Markdown 编辑器与弹窗共用此行为；隐藏与显示保持相同宽度，避免文字跳动。减少动态效果偏好下直接显示或隐藏。

## 第一次使用

默认案件为《二重证言》man-cat 版本的第一案：第 0 幕《无人接听的房间》。

“演绎”默认每次点击“继续”显示下一句，保留 NPC 与玩家先后说话的过程；真正的选项需要玩家选择。勾选“自动展开顺序对话”可快速测试，它只展开普通内容，遇到真实选项或行动等待就停止。切回逐次模式立即对后续内容生效，已显示的历史保留。

1. 接下回声地产的查验委托，解开储物间外扣，救出黑猫。
2. 给猫水与食物，检查半收行李、门槛痕迹与袖扣。现场只能先记为“暂停清房，待核验”。
3. 切换猫观察窗与门的过去行为，切回周渡移开低柜，再让猫沿窄缝取账页边角。
4. 行动等待期间可保存进度、重新开始、恢复；切换到“世界状态”触发询问邻居或老板娘，再回到“演绎”对话，其他调查不会因这次等待停下。
5. 推进 5 分钟，或在行为模拟中完成行动。受阻与取消不会提前给出物证，通路保留，可以重试。
6. 自由安排询问顺序，通过许可取得物证与垃圾房查验入口，再核验遗体、伤情、推车路线。
7. 在笔记中选择证据组合，手动确认闯窗盗窃、致命冲突、代理人夜访与移尸、阿澈最后可证实行动四项结论。
8. 起草报告，继续调查或按已确认事实提交。报告与房源处置随结论改变；阿澈此后的去向与生死始终保持未证实。

过早公开指控会触发离屏的清运提前：尚未留存的原始推车登记可能丢失，已经取得的证据保留，仍允许提交有限报告。猫的残留和未经核证的证言不会自动锁定责任。

实际模板在 [examples/man-cat-case-01.md](examples/man-cat-case-01.md)，原文同时作为编辑、预演与剧情图的输入。来源链接与改编说明保存在模板内。原案未修改；旧煤柜发现遗体是当前稿的待确认方案，模拟行动时长也不是正史时间。

模板菜单只提供该案，可从菜单新建或打开其他文档。旧商人模板已撤下；若浏览器仍停留在旧模板，首次加载会先保留改稿，再切换本案。用户导入的其他文档继续保留。原有基础运行示例仅留在 tests/fixtures 中用于回归测试，不参与网页模板或生产内容。

新版模板的邻居问话先连续说四句，再提供“追问人脸 / 复核站位”两个分支，各自回应后返回调用处。尚未改动的旧第一案（包括只保存了自由坐标的版本）会先备份为“无人接听的房间·更新前.md”，再载入新版；已改过正文、Ink 或其他属性的文档保留原稿。也可在文档菜单点击“载入新版模板”，系统先备份案件改稿再载入模板。进度槽不受模板更新影响。

## 编辑和保存

顶部“工作区”表示当前打开的文档。首次访问读取内置第一案；以后优先恢复此浏览器保存的当前文档和文件名。显示名称取自 Markdown 的 YAML `title`，没有该属性时使用第一个一级标题。点击名称可打开模板与最近文档菜单，也可新建或读入本地文件。草稿保存于当前浏览器，不同设备之间不自动同步。

顶栏通过“演绎”“分支”“世界状态”“事件记录”切换独立页面，每个页面占用完整工作区。页面内没有嵌套页签，也没有并排状态侧栏。演绎与世界页中的时间推进、存档控制共用同一份运行进度；分支页只显示故事结构。切换页面保留演绎进度、分支图段落、画布位置和未写回的对白改稿。顶栏页签支持左右方向键、Home / End。

在“分支”页点击剧情框的名称，在独立窗口中打开完整 Markdown 并定位到对应行；关闭后回到原来的段落与画布位置。点击框内内容可分别编辑每次显示的对白和玩家选项，一起写回。普通段落、双链、备注不参与执行，只有顶层 ink 代码块参与编译。支持在同一文档中放置多个顶层 ink 代码块，按文档顺序合并为一份 Ink。

顶部“教程”菜单提供“快速开始”和“语法速查”，按需打开独立窗口，不占用工作区。原文与教程都可以通过关闭按钮或 Escape 关闭，返回时保留预演进度。

- 文档改动在 450 毫秒后自动保存于当前浏览器。浏览器清理存储会删除这些草稿。
- “打开 Markdown”读入本地文件，“导出 Markdown”下载当前文档。导出不会自动覆盖原文件。
- 各示例的草稿分别保留，切换示例不会清除其已保存的修改。
- “保存进度”独立保存世界时间、完整 Ink 状态、每段对话当前等待继续的位置、手动点击历史、自动展开设置和未完成行为。当前版本提供一个本地进度槽；旧进度仍可恢复。
- “恢复”会载入存档所使用的作者文档；如果当前文档内容不同，会先保存“恢复前草稿”，可以从文档菜单重新打开。
- 修改可执行内容后，点击“从头预演”应用。修改普通 Markdown 说明或切换图的显示段落不会重置进行中的预演。
- 快捷键：⌘ / Ctrl + Enter 从头预演；⌘ / Ctrl + S 导出 Markdown。

## 图形编辑

对白统一为一种框，可以带玩家选项，也可以没有选项并直接连接后续框。顺序对白的合并与分解只改变显示粒度，选项始终属于对白的出口，不单列为另一种对白框；有无选项共用同一标题、图标与形状。

状态结果以青绿色的“条目：结果”显示。例如选中“接下旧公寓的查验委托”后，`~ case_started = true` 显示“已接下委托：是”。结果只读，面板没有状态语句输入框和写回按钮。每个结果按实际控制流标明“来自对话 / 行为 / 事件”等来源；点击来源会在画布上定位原始框，并标出具体选项。合并和分解视图都支持定位，来源在其他段落时会先切换段落再定位。汇合后有多个可能来源时逐一列出，不根据预演状态猜测唯一来源。对白中间的结果保留在对应点击位置；增减显示“原值 + / − 数值”，保留动态表达式。

条件查验使用黄色摘要，显示“全部满足 / 任一满足”、具体比较及各出口；数值匹配和逐条条件分别保留实际的判断顺序。点击“修改条件”打开独立控件，选择查验条目、比较方式和结果，再点击“应用条件”。组合关系、布尔值、数字、文字与另一个条目分别编辑，已完成、受阻等行为结果直接显示中文候选项。选项的出现条件也有独立入口。应用时只替换该条件的精确表达式范围，编译通过后同步原文与浏览器草稿，保留相邻对白、标签、分支和目标。条件面板不显示 Markdown 写回操作。未知表达式保留原有内容，绘图与条件编辑不会执行它们；复杂原文仍可通过框名打开。

“分支”页读取 Ink 编译器的分支结构，在选项、条件分支、行动等待、调用和结束处切分。段落栏的“合并顺序对话 / 分解顺序对话”控制自然展开内容的显示。合并时，一个框内上下排列每次继续的内容，分隔线中央的小箭头标出玩家点击位置；分解时，每次显示一个框，用正常方向的连线连接，真正的选项只出现在顺序链的最后。第一案的邻居段落合并时为 5 框，分解后为 14 框。

普通 Ink 输出换行对应一次点击，空行不增加点击，Ink glue（<>）连接的多行属于同一次输出。显示方式不会改写剧本或重置预演，图形偏好与自动展开偏好保存在当前浏览器。当前节点有未写回的改稿时，先写回或关闭节点编辑，再切换显示方式。

- 每种显示方式的唯一排布由结构、源码中的分支次序与文字尺寸决定；从左到右分层，用直角线避开框并减少交叉。旧 YAML layout 坐标不再参与显示。
- 可见选项的连接点位于选项条右侧，连线从该选项指向下一步；短引线穿过框内留白，外部连线继续按统一结构排布。拖拽交换后继时也以这个选项连接点为落点。
- 拖动过程中允许自由移动。拖到同组选项的后续框，交换整组选项及其内容；也可用节点面板中的“上移 / 下移”。
- 拖到允许交换的右侧出口，交换两条明确跳转的后继。只接受有明确地址、入口无歧义且不会新建循环的交换；落点高亮后才有效。放到空白或无效位置立即归位。
- 结构改动先编译再写回 Ink，不保存任意画布坐标。重新打开同一结构会得到同一排布。新增、删除、复杂改接可以点击框名，在原文中完成。
- 点击内容框打开节点面板：每次显示有独立编号和输入框，“玩家点击继续”标明真正的点击边界；glue 连接的片段共用一个编号并标为同时显示。选项有独立输入框，支持条件选项、嵌套选项、独立选择框和分解模式的最后一框；共用文字与只在选项中出现的文字分别编辑，保留 Ink 的输出含义。
- 修改使用编译器的精确文字范围，只替换变动的片段，保留标签、glue、相邻赋值、选项条件、具名标记和后续剧情。输入文字自动转义 Ink 标点，全部字段一起编译通过后写回。当前输入框对应一次显示，新增点击从框名打开原文编辑。动态表达式和共享同一行的内联条件片段只读，避免用渲染结果覆盖逻辑。
- 段落下拉菜单可查看局部或全篇，右上角可展开大图。回跳和跨段落跳转显示为可点击的继续 / 返回框，避免长线横穿整张图。
- 隧道和函数调用显示调用框及“返回后继续”出口，点击调用框查看子段；不把一个共享子段的返回错误地接到所有调用者。未知动态目标显示为源码引用。
- 字面量 emit 的事件关系用虚线显示；world.changed 的条件监听仍通过事件入口标签和运行记录观察，不猜测动态触发关系。

## 文档格式与行为协议 v1

YAML 可提供 id、title、schema: 1。graph_scenes 可配置局部显示范围，不影响执行；没有配置时按 Ink 段落分别显示：

~~~yaml
graph_scenes:
  - id: neighbor
    title: 邻居 · 逐句问话
    knots: [neighbor_testimony]
~~~

每个 Ink knot 可使用以下元数据：

~~~ink
=== clearance_pressure ===
# id: clearance_pressure
# title: 清运提前
# on: world.changed
# when: premature_accusation and not report_submitted
# once: save
~~~

id 是稳定节点身份；未提供时采用 knot 名称。on 指定外部事件，when 是 Ink 表达式。when 条件查询应没有副作用。

- start：开启预演时的事件。
- world.changed：任何可观察 VAR 值发生改变时，由运行时合并派发。不会依靠场景实体在线接收通知。
- 自定义事件：在“世界状态”页触发，或由 emit 发出。
- once: save：每份存档最多启动一次，在启动时登记，失败也不会自动重复。
- once: session：每次运行会话最多启动一次；恢复进度开启新的会话。
- 没有 once：每次匹配事件且条件成立时可启动，但已有该入口实例运行、等待或停在选项时不重复启动。

这些标签的语义是墨线扩展，不是原生 Ink 的自动监听功能。

~~~ink
VAR cat_path_result = ""

>>> await npc.move actor=cat to=wall_niche duration=5m result=cat_path_result

>>> start npc.move actor=cat to=wall_niche duration=5m as=cat_route
周渡：我守着通路。
>>> await cat_route result=cat_path_result

>>> emit event=case.reported
~~~

每条 >>> 语句写在一行，独立于其他输出，不使用 Ink glue（<>）与台词拼接；支持带引号的字符串参数。npc.travel 与 npc.move 都需要 actor、to、duration。时长可写 6h、30m、1d。

结果为 completed、blocked、cancelled 或 actor_missing。result 指向事先声明的 VAR。start 需要 as 句柄，后续 await 该句柄时指定结果变量。

模拟移动使用角色变量约定：

- cat_alive：如果为 false，移动请求失败或正在进行的移动被终止。
- cat_location：移动成功后设为目标逻辑地点。
- cat_state：移动期间设为 traveling；完成后为 idle，失败时恢复先前状态。

同一角色已有进行中的行为时，新的移动请求返回 blocked。当前仲裁是单一角色互斥；游戏中的优先级、抢占和多人演出协调仍需进一步扩展。

预处理会在指令后插入不允许前瞻执行的 Ink 外部函数边界。宿主收到等待请求后挂起对应 flow，直到结果返回才再次推进。因此不会因 Ink 的文本前瞻求值提前执行等待后的赋值。

## 核心与后续接入

- src/core/document.ts：Markdown 抽取、Ink 编译、源码映射和局部补丁。
- src/core/runtime.ts：共享 Ink 变量、独立 flow、事件调度、时间推进与存档。
- src/core/actions.ts：行为协议、注册接口和模拟执行器。
- src/graph：对白分支结构、固定规则排布与经过编译验证的结构补丁。
- src/components：网页编辑、剧情图、预演和调试面板。

核心不引用 React、Unity 或 Godot。FakeActionExecutor.register 可以替换或增加行为处理器；真实引擎需要实现接受请求与报告结果的接口。

Web 默认通过 RunnerOptions 的 autoExpandDialogue: false 启用逐次继续。continueDialogue(instanceId) 只推进对应 flow 的下一次输出；setAutoExpandDialogue(true) 展开暂停的普通对白，但不代选 Ink 选项、不推进世界时间或完成等待。直接使用 StoryRunner 时，默认仍是自动输出，以兼容已有的无界面逻辑测试与调用。

“导出编译运行包”包含 Ink JSON、入口登记、指令位置和源码行映射。它是后续引擎适配的输入，需提供 __loom_barrier 外部函数和墨线宿主协议。

固定 inkjs 2.4.0 及依赖锁文件。C# Ink 运行时尚未接入或做兼容性验证。

## 验证与边界

自动测试覆盖真实 Ink 执行、异步边界、并行剧情、角色互斥、失败与死亡、按顺序推进时间、半途存档恢复、普通 Ink 分支、图形局部补丁与源码行定位。
