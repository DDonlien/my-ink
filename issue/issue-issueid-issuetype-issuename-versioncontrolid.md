# Issue 标题（模板）

> 本文件仅演示格式，不是活动需求。复制为 `issue-<issueid>-<issuetype>-<issuename>-versioncontrolid.md` 后填写真实内容；按任务需要保留段落，不强制补空。

- ID：`<issueid>`（稳定且唯一；旧 ID 原样保留）
- 类型：`<DOC|PM|UX|UI|FE|BE|API|DB|DATA|CONTENT|QA|OPS|CI|SEC|ARCH|TOOL>`
- 状态：待处理 / 实现中 / 待检查 / 待用户验收 / 完成；以实际事实为准。
- 优先级：按实际需要填写。
- 范围 / 关联：目标路径、父子 Issue ID、旧条目来源或相关工作线。
- 版本管理标识：`versioncontrolid`（含义尚待定义，不推断为 commit、branch 或 change）。

## 目标与当前事实

说明用户希望完成的行为、明确范围和已确认的约束；本节随最新结论更新。

## 实现

- [ ] 一个明确、可交接的实现项。

## 检查

- [ ] 本次必要的代码 / 配置 / 引用检查；记录实际命令、结果与未覆盖范围。

## 用户验收

- [ ] 需要用户确认的效果或行为；待验收时保持未完成，不因实现或编译通过勾完父项。

## 当前阻塞与下一步

只写当前有效的阻塞和接手入口；没有时删除本节或明确写无。

## Comments

后续条目按时间与作者追加，记录用户补充、决策、行动、检查和交接。历史纠正另加一条，不改写旧 Comment；不要复制敏感输入。
